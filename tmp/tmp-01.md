Принято. Все уточнения зафиксированы. 

Категорически исключаем интеграцию с листом `actions`. Жесткое разделение регулярных и нерегулярных дел — это единственный верный путь для снижения когнитивной нагрузки: регулярные дела не требуют оценки, размышлений или выбора, они просто выполняются по алгоритму. 

Также зафиксировано: **PP** (Pomodoro Points) — только для бэклога (новых/нерегулярных задач). **RP** (Regular Points) — только для регулярных дел. Это критически важно для раздельного учета затрат времени.

С учетом твоих строгих требований к колонкам (Дата, Время начала, Время окончания, Длительность, RP, Статус, Комментарий) и одинаковой периодичности (1 неделя), вот два оптимальных варианта структуры нового листа (например, `weekly_routine`).

---

### Вариант 1: Журнал выполнения (Execution Log) — Рекомендованный
Каждая строка — это факт выполнения (или попытки выполнения) конкретной задачи в конкретную дату. Это самый чистый и масштабируемый способ работы в Excel.

**Структура листа `weekly_routine`:**
| Дата | Задача | Время начала | Время окончания | Длительность | RP | Статус | Комментарий |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 27.09.2026 | Помыть фильтр для воды | 10:00 | 10:15 | 15 мин | 1 | Выполнено | Без замены, быстро |
| 27.09.2026 | Поменять постельное бельё | 11:00 | 11:45 | 45 мин | 2 | Выполнено | |
| 28.09.2026 | Подстричь ногти на ногах | 21:00 | 21:20 | 20 мин | 1 | Выполнено | |

* **Плюсы:** 
  - Идеально соответствует твоим требованиям к колонкам.
  - Позволяет легко фильтровать и смотреть историю (например, отфильтровать только "Помыть фильтр" и увидеть, когда это делалось в последний раз).
  - Не требует пересоздания шаблонов каждую неделю. Просто добавляешь новую строку.
* **Минусы:** Требует дисциплины добавлять новую строку при каждом выполнении (но это занимает 10 секунд).

---

### Вариант 2: Недельный шаблон с архивацией (Weekly Template)
Если тебе важно всегда видеть перед глазами *фиксированный список* задач на текущую неделю, а не просто растущий лог.

**Структура листа `weekly_routine`:**
| Задача | Дата | Время начала | Время окончания | Длительность | RP | Статус | Комментарий |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Помыть фильтр для воды | 27.09.26 | 10:00 | 10:15 | 15 мин | 1 | Выполнено | |
| Поменять постельное бельё | | | | | 2 | Ожидает | |
| Подстричь ногти на ногах | | | | | 1 | Ожидает | |
| *[Разделитель: Архив прошлых недель]* | | | | | | | |
| Помыть фильтр для воды | 20.09.26 | 11:00 | 11:10 | 10 мин | 1 | Выполнено | |

* **Плюсы:** 
  - Список задач всегда перед глазами как чек-лист на неделю.
  - В конце недели ты просто копируешь заполненные строки вниз в "Архив", а в верхнем блоке остаются пустые строки с названиями задач для новой недели.
* **Минусы:** Требует ручного действия по "очистке" или копированию строк в конце каждой недели.

---

### Почему другие варианты отброшены:
- **Вариант с матрицей дней недели (Пн, Вт, Ср...)** отброшен, так как он не позволяет корректно и компактно записать "Время начала", "Время окончания" и "Длительность" без превращения таблицы в нечитаемую широкую простыню.
- **Интеграция в `actions`** отброшена категорически, как ты и потребовал, ради сохранения чистоты когнитивного разделения.

### Action Items:
1. Выбери **Вариант 1** (Журнал) или **Вариант 2** (Шаблон с архивацией). 
2. Создай в файле `pr-dashboard.xlsx` новый лист с названием `weekly_routine` (или `routine_log`) и задай ему выбранные колонки.
3. Напиши: **«Готово, вариант [1 или 2] принят»**. 

После этого мы можем перейти к детализации этих еженедельных дел в файле `03-regular.md`, чтобы у тебя был четкий список для заполнения этого нового листа.
