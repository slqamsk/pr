# Учёт баллов

| Обозначение | Название                                  | Определение |
| ----------- | --------------------- | --------------- |
| **I**       | **Importance — важность**                 | Насколько значим результат этого действия для моих важных целей/ролей. Оценивается от 1 до 5.                                                                                                      |
| **D**       | **Difficulty — трудность**                | Насколько трудно выполнить действие. Оценивается от 1 до 5.                                                                                                                                        |
| **N**       | **Novelty — новизна**                     | Насколько новым для меня является действие или способ его выполнения. Оценивается от 0 до 3.                                                                                                       |
| **Б₀**      | **Базовые баллы**                         | Баллы действия до учёта длительности, продуктивности и уместности. Сейчас рассчитываются по формуле `Б₀ = I + D + I×D + N`.                                                                        |
| **Время**   | **Время действия**                        | Фактически затраченное на действие время, включая технические перерывы.                                                                                                                            |
| **T**       | **Time — количество помидорок**           | Количество 30-минутных единиц времени, использованных действием.                                                                                                                                   |
| **P**       | **Productivity — продуктивность**         | Насколько продуктивно было использовано время длительного действия. 1,0 = 100% продуктивности.                                                                                                     |
| **C**       | **Current relevance / уместность сейчас** | Насколько правильным было выполнить это действие именно в данный момент. Сейчас оценивается вручную. 1,0 = полностью уместно; меньше 1,0 = действие стоило отложить ради более важных текущих дел. |

**Важное уточнение:** `C` — это не «важность» и не «срочность». Это именно **качество выбора момента**.

Баллы начисляются только действиям, которые я сознательно признал полезными/нужными.
Баллы начисляются за результат действия, а не за намерение.
Баллы  не мера объективной полезности дела.
Баллы  мера того, насколько хорошим выбором было выполнить это действие именно сейчас.
Важность действия оценивается от 1 до 5. Действия с важностью 0 не включаются в систему.
Трудность и новизна оцениваются до выполнения действия, чтобы не завышать их задним числом.
**Базовые баллы: Б₀ = I + D + I×D + N.**
**Двойная помидорка = 2 одинарные помидорки ≈ 1 час.**
**T = ⌈время / 25 мин⌉.**
Для действий длительностью не более одной двойной помидорки:

> **Б = Б₀.**

Для действий длительностью более одной двойной помидорки:
> **Б = Б₀ × (T / 2) × P**

где **P**  продуктивность, **0 < P ≤ 1**.
**P оценивается только для всего длительного действия, а не для каждой помидорки.**
Неполная одинарная помидорка считается полной.
Для действий, не требующих расхода времени, продуктивность не учитывается:
> **Б = Б₀.**

Плановость действия учитывается отдельно и не влияет на количество баллов.
Система баллов является экспериментальной и может изменяться после анализа результатов эксперимента.
